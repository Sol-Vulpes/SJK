# Test list shown by the `debug_panel` console command.
#
# PERSONAL: Sol's own checklist of the changes in SJK's main branch (Sol-Vulpes/SJK).
# The file is built into the client (include_str!) and parsed once at startup. Unit
# tests in debug_panel_data.rs check it, so `cargo test` catches a broken edit.
#
# Format: one block per entry, in display order. A block starts with "[id]"; the
# lines after it are "key: value". Lines starting with '#' and blank lines are ignored.
#
#   [entry-id]   Required. Lowercase letters, digits and '-'. Ticks are saved by this
#                id, so keep it when editing text or moving the block; a new id
#                starts untested.
#   area:        Required. Console & chat, Input, Menus & settings, HUD,
#                Rendering & effects, Audio or Gameplay.
#   title:       Required. One short line.
#   change:      What changed, 1-3 lines (repeat the key for each line).
#   test:        One "To test" step per line (repeat the key); at least one.
#   note:        Optional, highlighted; repeat for more lines.
#
# Text must be ASCII (the menu font draws bytes) and each line at most 96 characters
# after the key, or it ends in an ellipsis on narrow windows.
#
# Order: the panel keeps the file's order; the "# ----" lines only mark groups.
