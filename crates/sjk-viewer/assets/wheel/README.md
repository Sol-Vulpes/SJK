# Quick wheel icons

The quick wheels' icons ([quick_wheel.rs](../../src/quick_wheel.rs)): grey metal
discs in the style of Jedi Academy's neutral Force icons, generated by Sol as one
icon board (`Game_HUD_icon_design_board_2K`, 07/10/2026, kept outside the
repository) and cut out by [wheel_icons.py](../../../../scripts/wheel_icons.py).
They are SJK's own art; no retail image is used.

Each is 128x128, the UI atlas cell, on transparency with an anti-aliased round edge.
`sun.png` and `moon.png` are spares from the board, not yet on a wheel.

## Regenerating

With Python 3 and Pillow, numpy and scipy (`pip install pillow numpy scipy`), from
the repository root:

```sh
python scripts/wheel_icons.py Game_HUD_icon_design_board_2K.jpg crates/sjk-viewer/assets/wheel
```

The script finds the board's sixteen grey discs (its last two rows) and names them
in board order: drizzle, rain, storm, snow, ground_fog, clouds, maps_own,
weather_off, then third_person, nameplates, screenshot, hud, afk, cosmetics, sun,
moon.
